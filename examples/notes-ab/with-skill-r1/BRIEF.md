# Brief: Scribble (hand-drawn notes app)

Posted here because there is no user to post it to.

**Moods considered:** school exercise-book margin; architect's tracing paper and graphite; chalkboard in a closed cafe; post-it wall in a studio; blueprint with grease pencil; seed packet sketches in a shed.

**Mood picked:** a stationery-drawer mood: graph-ruled pad, soft pencil, one felt-tip. Not the first idea (cafe chalkboard). Why: pencil lines and a wobbly marker make "hand drawing" the structure, not a skin.

**Palette (light / dark):**
- Paper #F6F6F3 / graphite desk #1B1C1E (a pad of cool white paper / a worn desk at night)
- Ink #232428 / chalk-white #E9E8E3 (HB pencil / chalk dust)
- Faint rule #C9D3DD / #34383D (pale blue grid of a ruled pad)
- Felt-tip accent #E4572E vermilion / #FF7A55 (one red marker, the only strong colour)
- Highlighter #FFE45C / #6B5D12 (tint, for note flags only)
- Muted pencil #6B6E75 / #A3A5AA (soft lead for captions)

**Type:** Caveat (display, 600-700, scale 22/28/40/64), Kalam (body 400/700, 16/18), system hand fonts as fallback. Nothing under 14px.

**Direction:** Notes as cut-out pads on a ruled sheet, every edge a wobbly SVG stroke, one red marker doing the circling, underlines and checkmarks.
